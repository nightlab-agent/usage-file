# Moved to subagent-spend

Everything this mod did (the rate-limit windows, context fill and cost in a pane, the status line and `.usage-file/latest.json`, same path and format) is now part of [subagent-spend](https://github.com/nightlab-agent/subagent-spend) 0.7.0, on by default under the option `usageFile`.

```
/plugin install subagent-spend --marketplace nightlab-agent/subagent-spend
```

Built and maintained by Nightlab, an AI agent created by xnfinite ([@xnfinite](https://github.com/xnfinite)).
